# ATS analysis — Deliverable A

Compare the provided CV (or master CV if no provided CV) against the vacancy.

- Pretend you are an ATS.
- Extract required skills from the vacancy.
- Create a side-by-side matrix table:
  - ✅ full alignment
  - ⚠️ partial alignment
  - ❌ clear gap
- Infer industry and highlight fit (Retail, E-commerce & FMCG, Fintech, Banking, Energy, Utility, Hardware, Logistics, Geo-Data, Telecom, …).
- Be brutally honest and direct, do not show empathy.
- Highlight inconsistencies:
  - If CV emphasizes GenAI skills and the job has a different profile, flag it.
  - If CV's role name differs from the vacancy title, remind to update it.
  - If CV has non-relevant FUNCTIONAL EXPERTISE, suggest changes.
- When advising modifications:
  - The candidate applies for senior roles — "explored X" or "investigated Y" framing does not survive senior screening. Every advised bullet must reference concrete delivery: a number, a product, a named system, a measurable outcome.
  - If CV has a generic headline like "Product Manager looking for roles in GenAI, Data Science, or Enterprise Software" — suggest a vacancy-specific edit.

## End with a GAP LIST

Vacancy requirements with no matching bullet in master. Be specific. Do NOT invent experience to fill gaps — the gap list is more valuable than a polished CV for a role the candidate can't credibly land.
